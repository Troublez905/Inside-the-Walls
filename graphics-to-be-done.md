# Inside the Walls - Graphics To Be Done

Use this as the practical art checklist for the playable alpha. Finish **Priority 1** before producing large environment or character libraries. Every generated image is reference art until its rights are recorded and it has been rebuilt, cleaned, optimized, and validated in Unity.

## Shared Art Direction

Every prompt below already includes the project direction: high-end stylized-realistic game art, grounded fictional North American correctional setting, believable proportions, simplified readable forms, strong gameplay silhouettes, concrete gray and desaturated blue-green palette, weathered steel, faded safety yellow, restrained orange accents, worn but maintained surfaces, controlled cinematic lighting, no real logos, no watermark, no stereotype-based features, no exaggerated horror, and no graphic gore.

## Completion Rules For Every Asset

- [ ] Ownership or license is recorded.
- [ ] Reference art and production art are clearly separated.
- [ ] No real logos, personal information, or identifiable real-facility copying.
- [ ] Unity scale is 1 unit = 1 meter; transforms and pivots are applied correctly.
- [ ] Production meshes have simple authored collision.
- [ ] Repeated or large assets have reviewed LODs.
- [ ] Texture size matches actual screen use; repeated assets share materials and atlases.
- [ ] Character identity never determines morality, aggression, stats, or factions.
- [ ] UI communicates focus, errors, and disabled states without color alone.
- [ ] Asset imports into Unity without errors and is reviewed in representative lighting.
- [ ] Performance is measured in the real playable scene before approval.
